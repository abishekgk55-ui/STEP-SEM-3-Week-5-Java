# STEP SEM-3 — Week 5 Java

This repository contains the Week 5 Category C Java practice problems and assignment problems.

## Structure
- `Practice/Q1` through `Practice/Q5`: Practice problems
- `Assignment/Q1` through `Assignment/Q5`: Assignment problems

Each question is self-contained in `Main.java`.

## Compile and run
Open Terminal in the question's folder, then run:

```bash
javac Main.java
java Main
```

The solutions use only standard Java libraries.
